Slovo Portable for Windows x64
==============================

Extract the entire ZIP to a writable folder and open Start Slovo.cmd.
The launcher stores Slovo's settings, history, recordings and models in Data
next to the application. Keep Data when moving or updating this folder.

To keep the same data paths when using an external MCP client, set
SLOVO_DATA_DIR to the full path of this Data folder in the MCP configuration.
Keep "Launch at sign-in" off for a copy that you move between computers.
