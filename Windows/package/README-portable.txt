Slovo Portable for Windows x64
==============================

Extract the entire ZIP to a folder you can write to. Open Start Slovo.cmd.
The launcher stores settings, history, recordings, and models in Data next to
the app. Keep Data when you move or update the app folder.

For an external MCP client to use the same data, set SLOVO_DATA_DIR to the full
path of the Data folder in the MCP configuration. Leave "Launch at sign-in" off
if you move the portable app between computers.
