## Скачать

- **macOS 14.4+ · Apple Silicon.** `Slovo-0.5.1-macos-arm64.dmg`: откройте и перетащите Slovo в «Программы». Сборка подписана ad-hoc, без нотаризации Apple: при первом запуске может понадобиться «Всё равно открыть» в «Системные настройки → Конфиденциальность и безопасность».
- **Windows x64.** `Slovo-0.5.1-win-x64-setup.exe` ставит Slovo для текущего пользователя. `Slovo-0.5.1-win-x64-portable.zip` распакуйте целиком и запустите `Start Slovo.cmd`. Установщик не подписан, поэтому SmartScreen может показать предупреждение.
- `SHA256SUMS.txt` содержит контрольные суммы всех файлов.

Все пакеты собраны и проверены на GitHub Actions.

## Что изменилось с 0.5.0

- Первый публичный выпуск. Исходный код открыт под лицензией MIT, сведения о сторонних компонентах и моделях лежат в `THIRD-PARTY-NOTICES.md` и внутри пакетов.
- Если запись не удалось удалить с диска, Slovo сообщает об этом и сохраняет ссылку на файл для повторной попытки. «Удалить всю историю» показывает ошибку, если историю не удалось сохранить.
- ⌃⌘V больше не вставляет диктовку, которую вы удалили из истории.
- Предпросмотр очистки считает аудиофайлы так же, как сама очистка.
- Если микрофон отдал повреждённый кусок звука, Slovo предупреждает, что запись неполная, вместо того чтобы молча вставить текст с пропуском.
- Подсказки словаря обновляются, когда меняется история, и не мигают после удаления одного аудиофайла.
- В смешанной диктовке конец предложения внутри кавычек и скобок больше не мешает помощнику исправить букву «в».
- В настройках указан новый объём памяти GigaAM: около 350 МБ.

В версии для Windows новых функций нет: она по-прежнему на паузе.
