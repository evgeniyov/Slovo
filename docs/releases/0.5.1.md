## Download

- **macOS 14.4 or later on Apple Silicon.** Open `Slovo-0.5.1-macos-arm64.dmg` and drag Slovo to Applications. The build uses an ad hoc signature and has no Apple notarization. On first launch, you may need to select Open Anyway under Privacy & Security in System Settings.
- **Windows x64.** `Slovo-0.5.1-win-x64-setup.exe` installs Slovo for the current user. For the portable version, extract the entire `Slovo-0.5.1-win-x64-portable.zip` archive and run `Start Slovo.cmd`. The installer is unsigned, so SmartScreen may show a warning.
- `SHA256SUMS.txt` contains checksums for all files.

GitHub Actions built and checked all packages.

## Changes since 0.5.0

- This is the first public release. The source code uses the MIT license. Third-party component and model notices are in `THIRD-PARTY-NOTICES.md` and in the packages.
- If Slovo cannot delete a recording from disk, it reports the error and keeps the file reference so you can retry. "Delete all history" reports an error if it cannot save the history.
- ⌃⌘V no longer pastes dictation you deleted from history.
- The cleanup preview counts audio files the same way as cleanup itself.
- If the microphone returns a corrupt chunk of audio, Slovo warns you that the recording is incomplete and that the transcript may have a gap.
- Dictionary suggestions update when history changes. They no longer flicker when you delete one audio file.
- In mixed-language dictation, a sentence ending inside quotes or parentheses no longer prevents the helper from correcting the letter "в".
- Settings now show about 350 MB of memory for GigaAM.

Windows development remains on hold. This release adds no Windows features.
